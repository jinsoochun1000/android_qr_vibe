# QR CODE 리더기 안드로이드 앱 프로그램 바이브 코딩 

# 요구사항
- RQ 바코드 리딩  
- 2D 바코드 리딩 
- 1D 바코드 리딩 
- 단순히 리딩후 바코드 텍스트 보여주기 

# 기술 스택 
- Kotlin 또는 Java
- Android Phone 용 
- Android Studio Project 

# 기타 
- 한글코드 UTF-8 
- 개발결과 요약(상세) 내용은 개발자 가이드 용도로 README.md 파일 작성

# 추가 기능 
- 바코드 읽기가 성공되면 비프음 "삐" 소리가 나게 해달라
